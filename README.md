# Default Forecasting Model — 제조업 부도위험 스크리닝 대시보드

제조업(비상장+상장, 자산총계 100억~3,000억) 기업의 부도위험을 XGBoost로
스크리닝하는 정적 HTML 대시보드입니다. 빌드 도구·서버 없이 `index.html`을
브라우저로 열면 바로 동작합니다.

이 저장소는 **대시보드 화면만** 공유하기 위한 것으로, 모델 학습/데이터 수집
파이프라인(소스 코드, 원본 재무데이터)은 포함하지 않습니다.

## 보는 법

`index.html`을 더블클릭해서 열면 됩니다. 회사 행을 클릭하면 상세페이지로
이동해 재무지표 상세, 수익성·성장성 지표, 3개년 재무제표 원본, 최근 3년
외부감사인 감사의견, 부도확률 3개년 추이, 관련 뉴스(감성분석 포함)를 볼 수
있습니다.

GitHub Pages가 활성화되어 있다면 저장소를 내려받지 않고 링크만으로도 바로
볼 수 있습니다(저장소 Settings → Pages에서 활성화 가능).

## 데이터 기준

- 정적 스냅샷입니다 — 원본 프로젝트에서 주기적으로 갱신되지만, 이 저장소가
  자동으로 따라 갱신되지는 않습니다.
- 2025년 사업보고서를 제출한 제조업(비상장+상장) 기업 1,097개가 스크리닝
  대상이며, 과거 실제 부도사례 170건은 확률 눈금을 읽는 참고 기준점으로
  별도 표시됩니다.

## 알려진 한계

대시보드 상단 "⚠ 모델 한계" 배너에 상세 내용이 있습니다 — 표시되는 값은
확정된 부도 확률이 아니라 상대적 위험 순위(재무적 스트레스 점수)이며,
성장기업(R&D 적자기업) 오분류 가능성, 검증 성능의 한계, 스크리닝 범위(자산
100억~3,000억 제조업) 등을 포함합니다.

## 파일 구성

- `index.html` / `app.js` — 회사 목록: 검색/필터/정렬/페이지네이션
- `company.html` / `company.js` — 회사 상세페이지
- `style.css` — 스타일(라이트/다크 테마 대응, 두 페이지 공용)
- `data/*.json` — 회사 목록·지표·재무제표·감사이력·뉴스·부도확률 추이 데이터
- `data/*.js` — 위 JSON을 `window.__X__`로 감싼 버전(로컬 파일에서 열 때
  `fetch()`가 CORS로 막히는 걸 피하기 위해 `<script src>`로 로드)
